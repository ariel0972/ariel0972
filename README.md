## Projetos em destaque

### Gestor da Home Idiomas

Aplicação full stack para centralizar alunos, professores, turmas, presença e diário de classe. Desenvolvo o backend em NestJS e a interface em React.

O código inclui autenticação JWT/bcrypt e validações para presença por QR Code, como data, vínculo do aluno com uma turma e existência do diário de aula.

**Stack:** NestJS · TypeScript · MongoDB/Mongoose · React · JWT

[Backend](https://github.com/ariel0972/Home-Idiomas-Backend) · [Frontend](https://github.com/ariel0972/Home-Idiomas-Frontend)

### Libry Bot

Bot para Discord integrado ao Habitica. O projeto inclui persistência do vínculo entre contas e consulta de perfil pela API externa.

**Stack:** Node.js · JavaScript · Discord.js · MongoDB · API Habitica

[Repositório](https://github.com/ariel0972/Libry-Bot)
